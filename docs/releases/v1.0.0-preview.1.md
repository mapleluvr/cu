# cu v1.0.0-preview.1

Released 2026-08-14.

This is the first public, GitHub-only prerelease of `cu`, an evidence-bound Computer
Use CLI for Windows. It is intentionally a preview rather than stable `v1.0.0` because
two environment-dependent safety gates remain blocked on the release host.

## Included

- workspace-local run initialization and read-only status;
- bounded regional Windows capture with immutable observation evidence;
- topology inspection and topology-bound display constraints;
- strict `cu.action/v1` admission for finite pointer and keyboard action segments;
- durable effect journaling, D2 checkpoints, no-replay behavior, and fail-closed
  recovery;
- observation history and transactional archive cleanup;
- versioned JSON receipts and stable error classes for shell automation.

## Distribution

This release is not published to the npm registry. The GitHub release contains:

- `cu-1.0.0-preview.1.tgz`, an npm-format Windows package;
- `SHA256SUMS.txt`, containing a basename-only SHA-256 entry for that exact tarball.

The tarball manifest is restricted to 35 files: 30 runtime JavaScript modules, two
PowerShell helpers, `README.md`, `LICENSE`, and `package.json`. Source TypeScript,
tests, fixtures, local reviews, screenshots, `.cu/` state, and development artifacts
are excluded.

Follow the checksum-first installation instructions in the project
[README](../../README.md#installation). `private: true` remains set deliberately; npm
registry publication is a separate future decision.

## Verification

The release process requires all of the following at the exact release commit:

- pinned, least-privilege Windows hosted CI on Node.js 22.19.0;
- the complete 36-suite non-live L3 aggregation;
- four independently packed and installed public-command E2E suites;
- exact 35-file tarball manifest comparison, SHA-256 generation, and installation of
  the same hashed artifact;
- Gitleaks history and release-tree scans;
- helper source/build byte comparison and clean-build output-set comparison.

Local release-host results were 503 L3 tests discovered, 502 passed, zero failed, and
one environment-blocked file-symlink test. All four installed-command E2E suites
passed, including controlled target/decoy capture and input checks. Hosted CI must be
green before the tag and release are created.

## Explicit Preview Limitations

- Unrestricted full-desktop observation has not passed the required isolated Windows
  Sandbox/VM acceptance gate. The release host does not provide Windows Sandbox.
- The release host denied unprivileged file-symlink creation, so that confinement case
  remains environment-blocked rather than passed.
- Physical multi-monitor hardware was not available on the release host. Display
  topology behavior has synthetic coverage plus controlled single-display validation.
- Display IDs bind geometric placements in one topology; they are not physical device
  identities or Windows Task View virtual-desktop IDs.
- Exact Windows Task View virtual-desktop enumeration and selection are not supported.
- Stale or ownerless run locks block and are not automatically reclaimed.
- Process-interruption recovery is fail-closed; power-loss durability is not claimed.

Do not reinterpret these limitations as successful acceptance. Promotion to stable
`v1.0.0` requires new evidence for the blocked release gates.

## Security

Review the [security policy](../../SECURITY.md) before reporting suspected confinement,
input, evidence, privacy, or cleanup defects. Vulnerability details must use GitHub's
private vulnerability-reporting route, never a public issue or shared capture.
